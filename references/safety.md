# Safety

Use this skill for personal knowledge management, learning, research, and archival summaries.

## Do

- Use the user's own login state/cookies, stored locally.
- Summarize and transform content into personal learning notes.
- Attribute source author/title where available.
- Keep original images locally only for the user's reference.
- Extract short, high-value comment insights rather than dumping every comment.
- Respect the user's filesystem permissions and ask before writing outside the workspace.

## Do Not

- Ask for Rednote passwords.
- Share, print, or publish full cookie values.
- Help users bypass access controls, paywalls, account restrictions, or anti-abuse systems.
- Mass-republish others' posts as original content.
- Create a content farm or automated reposting workflow.
- Present private, login-only material as public domain.

## Public Sharing Language

Prefer:

- "整理自己的收藏"
- "个人学习备份"
- "把公开内容整理成 Obsidian 复习资料"
- "AI 辅助知识管理"

Avoid:

- "批量爬取小红书"
- "绕过限制"
- "搬运博主内容"
- "一键扒全网"
